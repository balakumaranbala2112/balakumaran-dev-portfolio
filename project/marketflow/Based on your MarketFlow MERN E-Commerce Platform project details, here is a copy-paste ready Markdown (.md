\#\#\# 📌 Project Overview

MarketFlow is a full-stack e-commerce platform built using the MERN stack that provides a complete online shopping experience with customer and admin workflows.

The platform allows customers to browse products, search and filter items, manage carts, place orders, complete payments, and interact through reviews and wishlists. It also includes an admin dashboard for managing products, categories, users, orders, coupons, and business analytics.

The project follows a scalable backend architecture with authentication, authorization, validation, security practices, API documentation, and production-ready development patterns.
